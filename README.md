# BookNook — Bookstore UX

**Task:** UX-EC-005 — Bookstore UI/UX  
**Format:** Responsive HTML/CSS/JavaScript prototype

## Included screens / flows
- Onboarding / welcome
- Home feed with featured books, categories and new discovery
- Category browse
- Book list with search, filters and sorting
- Book detail with author information and reviews
- Author directory + author page
- Book reviews with rating breakdown
- Reading list / saved books
- Shopping cart with quantity controls
- Checkout with shipping + payment UI
- Order confirmation
- User profile / order history
- Login / signup UI

## Design system from the brief
- Primary: #2E7D32 (Forest Green)
- Secondary: #FF6F00 (Warm Gold)
- Accent: #795548 (Brown)
- Background: warm white / cream
- Text: #1A1625
- Rounded corners, subtle shadows, gradient buttons
- Mobile-first responsive layout
- Bottom navigation on mobile

## How to run
1. Extract the ZIP.
2. Open `index.html` in Chrome/Edge/Firefox.
3. No build tools or server are required.

The project stores the demo cart and reading list in browser `localStorage`, so interactions persist after refresh.

## Submission note
This is an interactive front-end implementation of the supplied internship brief. It is intentionally self-contained and uses CSS-generated book covers so it does not depend on external image assets.
